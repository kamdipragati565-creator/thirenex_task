# Thiranex Task 3 – Exploratory Data Analysis (EDA)

## 📊 Project Overview

This project is part of the **Thiranex Internship – Task 3**.
The project performs **Exploratory Data Analysis (EDA)** on the **Netflix Movies and TV Shows dataset**.

The main purpose is to clean the dataset, explore its features, identify patterns and trends, and present the findings using statistical analysis and visualizations.

## 🎯 Objectives

* Understand the structure of the Netflix dataset
* Handle missing values
* Remove duplicate records
* Perform statistical analysis
* Compare Movies and TV Shows
* Analyze countries and genres
* Study content ratings
* Analyze release-year trends
* Analyze movie duration
* Identify numerical correlations
* Create meaningful visualizations

## 🛠️ Technologies Used

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Seaborn**
* **Google Colab**
